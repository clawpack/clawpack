# Contributing to Clawpack

## Contributing with AI assistance

Clawpack welcomes AI-assisted contributions under our [AI policy](AI_POLICY.md). Before opening a PR that used AI tools:

- [ ] I understand every line and can explain it in review, in my own words.
- [ ] For a non-trivial change, there's an issue describing the problem.
- [ ] Any numerical decisions are mine, and results-affecting changes include verification evidence (manufactured/exact solution, convergence rate, or conservation/well-balancing checks).
- [ ] Commits where AI meaningfully helped carry an `Assisted-by:` trailer and are signed off (`git commit -s`).
- [ ] The PR description opens with my own short summary; any AI-written detail is below it and marked.
- [ ] No proprietary or NDA'd material went into prompts, and nothing is derived from license-incompatible code.
